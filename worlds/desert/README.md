# Desert

The world behind the pale sand pool in the wood.

This folder is a separate page with its own code, so the desert can run by
entirely different rules from the wood. Right now it is only an arrival: you
rise out of a pool among dunes, can look around, and can dive back into the
pool to go home. What happens here is still to be designed.

- You arrive from the wood at `worlds/desert/index.html`.
- Diving into the pool returns to `../../index.html#from-desert`, which makes
  the wood start you beside the desert pool.
