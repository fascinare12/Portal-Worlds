# Credits

## Stroke-order data

`strokes.json` holds the strokes of each hiragana, in the order they are
written. It is taken from the [KanjiVG](https://kanjivg.tagaini.net/) project
by Ulrich Apel, and is used and shared under the
[Creative Commons Attribution-Share Alike 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
licence. The file here is a reduced form of the original: only the stroke
paths of the hiragana, with all other markup removed. Under the terms of that
licence, this file may be reused by anyone on the same terms, with the same
credit.
